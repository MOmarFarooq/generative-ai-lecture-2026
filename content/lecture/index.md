## 3. AI Agents - From Tool to Colleague
### 3.1 What is an AI Agent?
So far, we've looked at AI that responds to prompts. You ask, it answers. That's the model most people know.

But there's a more powerful paradigm emerging: AI Agents.

**Definition**
- An AI agent is a software system that combines a large language model with the ability to use tools, maintain memory, and execute multi-step plans autonomously.

| Aspect | Standard AI (Chatbot) | AI Agent |
|--------|----------------------|----------|
| **Response style** | Responds to single prompts | Plans and executes multi-step tasks |
| **Action capability** | Cannot take action outside chat | Can use tools (browser, terminal, APIs, files) |
| **Memory** | No memory between conversations | Maintains context across a task |
| **Control** | You guide every step | Works autonomously toward a goal |
| **Example** | "How do I book a flight?" → Returns instructions | "Book me a flight to Shanghai next Tuesday" → Actually books it |

**Agent Examples in 2026**

| Agent | What It Does | Where to Use |
|-------|--------------|---------------|
| **Claude Code** | Terminal-based coding agent, reads your codebase, writes multi-file edits, runs tests | Command line |
| **Cursor 2.0** | AI-native code editor with agent mode, plans and executes code changes | VS Code fork |
| **WPS Lingxi Agent** | Office agent, edits slides, creates charts, formats documents | WPS Office |
| **Wingman** | Personal assistant, manages email, calendar, CRM | Web/mobile |
| **Devin** | Autonomous software engineer, builds entire features from specs | Web platform |

## 5. A Glance at Generative AI: How It Actually Works

1. We've spent most of this class looking at what generative AI can do. Now let's take just a few minutes to understand how it works under the hood.
2. You don't need to be a computer scientist to grasp this. Two concepts will give you a solid mental model: **tokenization** and **autoregressive generation**.

### 5.1 Everything is a Token

**The Core Idea**
- AI models don't see letters, pixels, or sound waves. They see only tokens—numerical chunks of data.
- Think of it like this: You're reading a book, but instead of letters, every word is replaced by a number from a giant dictionary. The AI processes sequences of these numbers.

**Text Example:**

The sentence "AI is smart" becomes:

<div style="background-color: #f0f0f0; padding: 15px; border-radius: 8px; border-left: 4px solid #666;">

- [AI] → Token #2456
- [is] → Token #89
- [smart] → Token #4721
</div>

The model works with [2456, 89, 4721], not the letters themselves.

**The "Strawberry" Problem**

Here's a fun way to see tokenization in action. Ask any AI: "How many 'r's are in the word 'strawberry'?"

Many models answer "**2**" instead of the correct "**3**" .

Why? Because the word gets split into tokens like [straw] [berry]. The AI never "sees" the individual letters, it only sees the token chunks. It can't count what it can't see.

This small quirk reveals a big truth: **AI processes language very differently than humans do**.

**Beyond Text**

In 2026, this same principle applies across all media:
| Input Type | Tokenized As |
|------------|--------------|
| Text | Word or sub-word chunks |
| Images | Small square patches of pixels |
| Audio | Short slices of sound waves |
| Video | Sequences of image tokens across time |

Everything becomes numbers in the same mathematical space. That's why one model can now handle text, images, audio, and video together.

### 5.2 Autoregressive Generation
**The Core Idea**

Generative AI doesn't create entire outputs at once. It generates one token at a time, and each new token depends on everything that came before it.

The term comes from auto (self) and regressive (looking back). The model constantly "looks back" at what it just generated to decide what comes next.

**Step-by-Step Process**

Let me walk through a simple example. Imagine prompting: "The cat sat on the"

<div style="background-color: #f0f0f0; padding: 15px; border-radius: 8px; border-left: 4px solid #666;">

**Step 1:** Model receives tokens → [The] [cat] [sat] [on] [the]

**Step 2:** Model predicts next token → [mat] ← This is token y₁

**Step 3:** Model now feeds everything back to itself:
        [The] [cat] [sat] [on] [the] [mat]

**Step 4:** Based on this expanded sequence, it predicts → [and] ← token y₂

**Step 5:** Feed back again:
        [The] [cat] [sat] [on] [the] [mat] [and]

**Step 6:** Predict → [purred] ← token y₃

... This repeats until the model generates a special `<END>` token.

</div>

**Visual Summary**:

<div style="text-align: center;">
  <img src="/generative-ai-lecture-2026/data/VS.png" width="500"/>
</div>

**Why This Explains Two Key Behaviors**

1. Coherence: Because every new token is generated with awareness of all previous tokens, the output stays consistent and logical. The model is constantly "reading" what it just wrote.

2. Hallucinations: A small mistake early in the chain can cascade. If token y₅ is wrong, tokens y₆ through y₅₀ will all be built on that faulty foundation. The model confidently continues down a path that started with an error.

**Application to Video**

The same principle explains why 2026 video AI looks so smooth. Each frame is generated based on all previous frames, maintaining continuity of motion, lighting, and characters.

**Summary Table**
| Concept | What It Means | Why It Matters |
|---------|---------------|----------------|
| Tokenization | All inputs become numbers | Explains how AI handles text, images, audio together |
| Autoregressive Generation | One token at a time, looking back at history | Explains coherence and why hallucinations happen |

That's it, two concepts that unlock how generative AI actually works.

Everything becomes tokens. Everything is generated one piece at a time, looking back at what came before.

With these two ideas in mind, you now understand more about how AI works than most people who use it every day.
